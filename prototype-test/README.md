# AI 简历平台可用性测试原型

基于 React、Vite 和 TypeScript 的本地交互测试版。项目使用 27 张已导出的 1920×1080 原型图作为视觉底图，以真实 HTML 控件覆盖登录、创建、模块管理、排序、JD 输入、AI 决策、分享、导出、额度不足和支付模拟等关键操作。

## 本地运行

```powershell
cd E:\Resume-opt\prototype-test
npm install
npm run dev
```

浏览器打开终端显示的本地地址。固定测试账号已经预填：

## 测试工具

点击右下角“测试工具”可：

- 调整 AI、诊断、导出和支付的模拟延迟；
- 切换支付成功或未完成分支；
- 模拟额度不足与自动保存失败；
- 快速跳转到各流程起点；
- 导出包含时间、页面、操作和明细的 JSON 测试记录；
- 清空本地记录并重置测试。

测试记录只保存在当前浏览器的 `localStorage` 中，不会上传。

## 建议测试任务

1. 登录并创建一份前端开发简历，选择 ATS 单栏模板。
2. 打开模块管理，隐藏“校园经历”，再调整模块顺序。
3. 收起左右面板后恢复，确认可以退出专注预览。
4. 使用 AI 优化，分别尝试接受、拒绝和重新生成。
5. 粘贴固定 JD，查看匹配结果并定位修改。
6. 运行简历诊断并定位一个问题。
7. 打开分享和 PDF 导出弹窗，并用 Esc 关闭。
8. 模拟额度不足，进入会员方案，分别测试支付成功和未完成。
9. 导出测试 JSON。
